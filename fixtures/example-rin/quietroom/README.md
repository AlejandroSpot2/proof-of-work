# Quietroom (EXAMPLE)

Turns raw user feedback into drafted issues. An AI model clusters the feedback, and each cluster becomes a draft issue that must match a JSON schema before anyone sees it.

EXAMPLE project: synthetic, created for a demo. Not a real product.

Clusters are ranked by how many distinct users raised them.

Feedback text is treated as data, never as instructions to the model.

Evaluated only on a 20-example synthetic set. Quality on real feedback is unknown.
